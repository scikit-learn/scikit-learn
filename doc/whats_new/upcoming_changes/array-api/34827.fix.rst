- Fixed :func:`~metrics.confusion_matrix_at_thresholds` to accumulate weighted
  counts with an adaptive fixed-point integer cumulative sum on ``float32``-only
  array API devices, preventing floating-point precision saturation when the
  effective positive weight exceeds :math:`2^{24}` samples and avoiding
  underflow of pre-normalized or tiny sample weights under a fixed micro-unit
  scale.
