- The HTML representation of estimators is now fully keyboard accessible: the
  collapsible estimator boxes are built with native `<details>` and
  `<summary>` elements, so they can be reached and toggled with a keyboard
  and are announced as disclosure widgets by screen readers. Documentation and
  parameter tooltips are also shown on keyboard focus and can be dismissed
  with the `Escape` key.
