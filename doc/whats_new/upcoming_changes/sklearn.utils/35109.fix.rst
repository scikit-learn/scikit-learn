- :func:`utils._array_api.move_estimator_to` no longer converts array attributes
  with non-numeric and non-boolean data types (such as string or object arrays,
  e.g. ``classes_`` or ``feature_names_in_``). Such attributes are now preserved
  as-is instead of being converted to the target array namespace.
  :pr:`35481` by :user:`Alok Yadav <Alok-Yadav25>`.
