- :func:`utils.estimator_checks.check_array_api_input` now takes `X_ns_and_device`
  and `other_ns_and_device` instead of `array_namespace` and `device_name`, so
  that it is able to also cover inputs from mixed namespaces/devices.
  :func:`utils.estimator_checks.check_array_api_mixed_inputs`, which as just a thin
  wrapper, is removed; the same check is still run by
  :func:`utils.estimator_checks.check_estimator` and can still be referred to as
  `"check_array_api_mixed_inputs"` in `expected_failed_checks`.
  By :user:`Lucy Liu <lucyleeow>`.
