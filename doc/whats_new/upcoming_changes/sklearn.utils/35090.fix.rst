- :class:`utils.parallel.Parallel` no longer resets the warning filters in tasks
  that run in the caller's process (thread-based backends, or `n_jobs=1`): they
  use the caller's filters directly. With many threads, resetting them could
  corrupt the process-wide warning filters (losing the user's filters and raising
  spurious warnings) on Python without context-aware warnings, and was costly on
  free-threaded Python.
  By :user:`Arthur Lacote <cakedev0>`.
