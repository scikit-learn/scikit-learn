- :func:`utils.check_array` with `copy=False` and `force_writeable=True` now
  copies the read-only array that pandas Copy-on-Write (the default in
  pandas >= 3) returns for a DataFrame, instead of making it writeable. This
  fixes estimators with `copy=False`, such as
  :class:`preprocessing.StandardScaler`, modifying other DataFrames that share
  memory with the input.
  By :user:`Dea María Léon <deamarialeon>`.
