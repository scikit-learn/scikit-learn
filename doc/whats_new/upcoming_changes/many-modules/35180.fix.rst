  :class:`neighbors.KNeighborsClassifier`, :class:`neighbors.NearestNeighbors`
  and :func:`metrics.pairwise_distances_argmin`) no longer runs on a single
  thread with threadpoolctl 3.7 and OpenBLAS's OpenMP threading layer.
