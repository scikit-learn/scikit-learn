- The parameter `multiclass_colors` of :class:`inspection.DecisionBoundaryDisplay` is
  deprecated in favour of `target_colors`, and the attribute `multiclass_colors_` is
  deprecated in favour of `target_colors_`. The old names will be removed in 1.12.
  The new names no longer suggest that the colors only apply to multiclass problems.
  By :user:`Anne Beyer <AnneBeyer>`.
