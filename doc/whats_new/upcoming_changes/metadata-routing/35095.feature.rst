- :class:`~ensemble.BaggingClassifier`, :class:`~ensemble.BaggingRegressor`,
  :class:`~ensemble.IsolationForest` and :class:`~multiclass.OutputCodeClassifier` now
  expose their own `sample_weight` consumption via `add_self_request` and auto-request
  `sample_weight` on their methods (`fit` and / or `score`) when metadata routing and
  auto-requests are enabled via :func:`~sklearn.set_config`.
