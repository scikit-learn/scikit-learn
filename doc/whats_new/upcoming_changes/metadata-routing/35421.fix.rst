- Scorers created with :func:`~metrics.make_scorer` and :func:`~metrics.get_scorer`
  now correctly route metadata to the response method they call on the estimator
  (e.g. `predict`, `predict_proba` or `decision_function`) when it requests them.
  This applies in :func:`~model_selection.cross_validate`,
  :func:`~model_selection.cross_val_score`, :func:`~model_selection.learning_curve`,
  :func:`~model_selection.validation_curve`,
  :func:`~model_selection.permutation_test_score`, the ``*SearchCV`` estimators,
  :class:`~model_selection.TunedThresholdClassifierCV`,
  :class:`~feature_selection.RFECV` and
  :class:`~feature_selection.SequentialFeatureSelector`. Previously, this metadata was
  silently dropped when scoring, e.g. for a :class:`~pipeline.Pipeline` step requesting
  it in `transform`.
  By :user:`Thomas Moreau <tomMoral>` and :user:`Hamza Abdelhedi <BabaSanfour>`.
