- scikit-learn estimators that inherit from :class:`~sklearn.base.BaseEstimator` now
  auto-request `sample_weight` on methods that accept it when metadata routing and
  auto-requests are enabled via :func:`~sklearn.set_config`. This includes consuming
  :term:`routers <router>` that expose those methods via ``add_self_request`` (for
  example CV estimators and other meta-estimators that consume `sample_weight` in
  ``fit`` and/or ``score``). Third-party estimators can opt in with
  :class:`~sklearn.utils.metadata_routing.AutoRequestMixin`.
  By :user:`Stefanie Senger <StefanieSenger>`.
