- |Feature| scikit-learn estimators that inherit from
  :class:`~sklearn.base.BaseEstimator` now auto-request `sample_weight` on
  methods that accept it when metadata routing and auto-requests are enabled via
  :func:`~sklearn.set_config`. Third-party estimators can opt in with
  :class:`~sklearn.utils.metadata_routing.AutoRequestMixin`.
  By :user:`Stefanie Senger <StefanieSenger>`.
