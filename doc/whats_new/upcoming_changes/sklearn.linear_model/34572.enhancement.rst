- :class:`linear_model.ElasticNetCV`, :class:`linear_model.LassoCV` and
  :class:`linear_model.MultiTaskElasticNetCV` as well as :func:`linear_model.enet_path`
  and :func:`linear_model.lasso_path` are now faster. The (relative) speed-up is larger
  for lower convergence requirements (larger values of `tol`) and is achieved by
  avoiding recalculating the residuals and column norms of `X` for each penalty `alpha`
  along the path.
