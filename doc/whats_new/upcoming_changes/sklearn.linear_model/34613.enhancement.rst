- :class:`linear_model.ElasticNetCV`, :class:`linear_model.LassoCV` and
  :class:`linear_model.MultiTaskElasticNetCV` now avoid prematurely converting `X` to
  an F-contiguous array or a sparse CSC array because the inner cross validation takes
  subsamples of `X` which then need the same conversion again, anyway. So this PR can
  avoid memory copies of `X`.
