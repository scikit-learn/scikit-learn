- The solvers ``"newton-cholesky"`` and ``"newton-cd-gram"`` compute the full Hessian
  matrix. For dense `X`, this computation now exploits the symmetry of
  `X.T @ diag(w) @ X`, making this *sandwich matrix product* up to ~1.8 times faster.
  As this product is the main cost of these solvers, fits become correspondingly faster,
  with gains growing with `n_features` and being negligible for fewer than ~10 features.
  This benefits :class:`linear_model.LogisticRegression`,
  :class:`linear_model.LogisticRegressionCV`, :class:`linear_model.GammaRegressor`,
  :class:`linear_model.PoissonRegressor` and :class:`linear_model.TweedieRegressor`
  when one of these solvers is used.
  By :user:`Christian Lorentzen <lorentzenchr>`.
