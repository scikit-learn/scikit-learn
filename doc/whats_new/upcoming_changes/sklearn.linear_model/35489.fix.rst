- The line search of the solvers `"newton-cholesky"`, `"newton-cd"` and
  `"newton-cd-gram"` of :class:`linear_model.LogisticRegression`,
  :class:`linear_model.GammaRegressor`, :class:`linear_model.PoissonRegressor` and
  :class:`linear_model.TweedieRegressor` now uses the approximate Armijo condition of
  :doi:`Hager & Zhang (2005) <10.1137/030601880>` to accept steps for which the change
  of the loss is of the order of machine precision. It replaces the check on the sum
  of absolute gradients.
  Furthermore, if the line search fails, the lbfgs fallback now starts from the
  coefficients before the line search instead of the last rejected trial step.
  By :user:`Christian Lorentzen <lorentzenchr>`.
