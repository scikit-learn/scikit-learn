- The `solver="liblinear"` as well as its two related parameters `dual` and
  `intercept_scaling`, are deprecated for :class:`linear_model.LogisticRegression` and
  :class:`linear_model.LogisticRegressionCV`. Instead, particularly for L1 and
  ElasticNet penalties, the newly introduced `"newton-cd"` and `"newton-cd-gram"`
  solvers are recommended replacements.
  Note also that liblinear is the only solver that does not support the multinomial
  loss for multiclass problems and we vendor a very old version of it.
  By :user:`Christian Lorentzen <lorentzenchr>`.
