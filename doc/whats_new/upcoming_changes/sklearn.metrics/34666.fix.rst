- :func:`metrics.pairwise_distances` and :class:`neighbors.LocalOutlierFactor` (along with other distance-based estimators) no longer incorrectly yield corrupted distances and misclassify all samples as inliers when ``metric="mahalanobis"`` and ``n_jobs > 1``. This thread-safety bug caused by Scipy's internal state was avoided by routing these metrics to a process-based parallel backend.
